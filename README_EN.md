A skill for operating Unity Editor from Claude Code. Uses WebSocket communication to support 60+ operations including GameObject creation, material settings, and scene management.

## System Requirements

| Item | Requirement |
|------|-------------|
| OS | **Windows 11 only** |
| Unity | 6.x (6000.x) recommended |
| Render Pipeline | URP compatible |
| Python | 3.10 or later |
| Claude Code | **Pro plan or higher required** (Free plan not supported) |

> **Note**: Currently tested only on Windows 11. Mac/Linux are not supported.

## Why SKILL?

This project uses SKILL instead of MCP (Model Context Protocol).

| Aspect | SKILL | MCP |
|--------|-------|-----|
| Setup | Just copy files | Requires server startup & config files |
| Security | All code is public & readable | Server internals may be opaque |
| Customization | Users can modify freely | Requires server-side changes |
| Context Efficiency | Loaded only when needed | Always-on connection consumes context |
| Debugging | Direct code inspection | Requires server log analysis |
| Dependencies | Minimal (Python + WebSocket) | Depends on MCP server implementation |

## Installation

### 1. Unity Setup

#### 1.1 Install WebSocketSharp

1. Download DLL from [websocket-sharp](https://github.com/sta/websocket-sharp)
   - Get `websocket-sharp.dll` from Releases
   - Or via NuGet: `Install-Package WebSocketSharp -Pre`
2. Place the DLL in `Assets/Plugins/` folder of your Unity project

#### 1.2 Install Editor Extension

Copy the `Assets/ClaudeAgent/Editor/` folder to your Unity project

#### 1.3 Required Packages

Install via Package Manager:
- `com.unity.nuget.newtonsoft-json` (JSON.NET)

Optional:
- `com.unity.probuilder` (if using ProBuilder operations)

#### 1.4 Start Unity Command Server

In Unity Editor: **Tools → Unity Command Server**

Click "Start Server" when the window opens (runs on port 8766)

### 2. Claude Code Setup

#### 2.1 Python Dependencies

```bash
pip install -r ClaudeCode/requirements.txt
```

Or install individually:
```bash
pip install websockets>=12.0
pip install pywin32>=306
```

#### 2.2 Deploy the Skill

Copy the `ClaudeCode/.claude/skills/unity-editor-operations/` folder to your Claude Code skills directory

## Usage

Invoke the `unity-editor-operations` skill in Claude Code.

## Troubleshooting

### Connection Error

1. Verify Unity Command Server is running
2. Check if port 8766 is available
3. Check firewall settings

### Unity Window Not Activating

- Verify `pywin32` is correctly installed
- Verify Unity window title contains " - Unity "
